# Project Images

This folder contains project preview images for the portfolio.

## Required Images:

- `ecommerce.jpg` - E-Commerce Platform preview
- `taskmanager.jpg` - Task Management App preview  
- `weather.jpg` - Weather Dashboard preview
- `portfolio.jpg` - Portfolio Website preview
- `blog.jpg` - Blog Platform preview

## Image Specifications:

- **Size**: 400x300px recommended
- **Format**: JPG, PNG, or WebP
- **Quality**: High resolution for retina displays

## Notes:

Place your actual project screenshots in this folder with the exact filenames above. 
If images are not found, the ProjectCard will show a fallback rocket icon.
